# 英文字母練習卷

給幼稚園小朋友的 A–Z 英文字母練習卷，一個字母一張 A4，可以列印，也可以在電腦或平板上點著玩。

## 內容

每張練習卷有：

- 大大的字母（大寫紅色、小寫黃色）
- 4 張單字圖卡，開頭字母標紅色（X 標的是字裡的 x，例如 box、fox）
- 一句簡單的句子
- **Find it**：圈出開頭是這個字母的圖
- **Write it**：在四線格上描寫字母和單字，再自己寫一行

## 互動功能（用 Chrome 或 Edge 開）

- 點字母、圖卡、句子、描寫列都會念英文
- 左上角 ▶ Listen 會從頭念一次
- Find it 點圖來圈：對了會念 "Yes!"、錯了會抖一下念 "Try again!"，全部找到會出現 🎉 Great job!
- 工具列可以切換慢速念、隱藏中文、換一組 Find it

## 列印

按「🖨️ 列印 A4」，紙張選 A4、邊界選「無」、勾選「背景圖形」。選單選「全部字母」可以一次印出 26 張。
列印時不會印出圈選和按鈕，紙本是空白的練習卷。
